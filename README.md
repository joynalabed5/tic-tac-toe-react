# React + Tailwind CSS Tic-Tac-Toe 🎮

A classic, interactive **Tic-Tac-Toe** game built using **React** and dynamically styled with **Tailwind CSS**. This project features fully responsive components, modern UI/UX design, real-time state management, and accurate victory detection.

## ✨ Features

- 👥 **Two-Player Local Mode:** Smooth turn alternation between `X` and `O`.
- 🎨 **Tailwind CSS Styling:** Modern UI utilizing utility classes, and a polished color palette.
- 🏆 **Smart Victory Detection:** Instantly evaluates rows, columns, and diagonals for a win or declares a draw.
- 🔄 **Instant Reset:** Clean one-click button to reset the state and restart the match immediately.
- 📱 **Fully Responsive:** Perfectly optimized for mobile, tablet, and desktop screens using Tailwind's breakpoint modifiers.

## 🛠️ Tech Stack

- **Framework:** React.js (Functional Components & Hooks)
- **Styling:** Tailwind CSS (Utility-first framework)
- **Build Tool:** Vite (or Create React App)

## 📦 Getting Started

Follow these steps to run a copy of this project locally on your machine.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) installed.

### Installation & Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**

   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Install the dependencies:**

   ```bash
   npm install
   ```

4. **Launch the local development server:**
   ```bash
   npm run dev
   ```

Open your browser and navigate to the provided local URL (usually `http://localhost:5173`) to view and play the game!
